# BIO2105 Regression Analysis

## Project Overview

This project focuses on regression analysis using two datasets: the Black Cherry Trees Dataset (trees) and the American Women Height and Weight Dataset (women).

## Objectives

- Perform linear regression analysis.
- Create scatter plots and regression models.
- Construct ANOVA tables and calculate sums of squares.
- Evaluate regression assumptions using diagnostic plots.
- Interpret statistical results.

## Files Included

- BIO2105_Regression_Analysis.R
- BIO2105_Regression_Analysis.Rmd
- BIO2105_Regression_Analysis.html
- README.md

## How to Run

Open the BIO2105_Regression_Analysis.Rmd file in RStudio and click Knit to generate the HTML report.
